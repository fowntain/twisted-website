# Twisted Website

A modern, minimal website for Twisted, made by a fan.

![image](https://github.com/user-attachments/assets/a253d7fb-6b03-4fc9-a399-cafa0469a57f)

## Features

- Minimalist and clean UI  
- Built-in trailer showcase
- Feature list and descriptions of the game
- Fast and lightweight

## Deployment
1. Install required packages (using `--legacy-peer-deps` due to package conflicts, it works fine): 
`npm install --legacy-peer-deps`

2. Build the app: 
`npm run build`

3. Start your server: 
`npm start`

## Built With

- React  
- Tailwind CSS

## About Twisted

Twisted is an exhilarating Roblox storm chasing experience that puts you in the heart of tornado alley in the fictional state of Keysota. Chase, track, and witness the raw power of tornadoes as they tear across the landscape.
More info: [Twisted game](https://www.roblox.com/games/6161235818/Twisted-BETA)
